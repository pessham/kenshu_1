## 質問5: 詳細なコンテクスト情報

**この質問が最も重要！品質を大きく左右します**

**良い答え方:**
```
a) BookingController, PaymentService
b) SQLSTATE[23000]: 外部キー制約違反
c) users, bookings, vehicles, paymentsテーブル
e) OWASP Top 10対策必須
```

**もっと良い答え方:**
```
a) よく使うクラス:
   - User::class, Booking::class, Vehicle::class
   - BookingController, PaymentController
   - PaymentService（決済処理の共通化）

b) よく遭遇するエラー:
   - SQLSTATE[23000]: Integrity constraint violation
   - 419 Page Expired（CSRFトークンエラー）

c) DBスキーマ:
   - users, bookings, vehicles, payments
   - REST API: /api/bookings, /api/vehicles

e) セキュリティ:
   - OWASP Top 10対策必須
   - SQLインジェクション・XSS・CSRF対策

f) パフォーマンス:
   - レスポンス500ms以内
   - N+1クエリ禁止

g) 外部連携:
   - レガシーPHPシステムとREST API連携
   - Stripe決済API使用
```

**スキップする場合:**
```
該当なし
```
または
```
スキップ
```

**ポイント:** 
- わかる項目だけ答えればOK
- 詳しく書くほど、AIの回答精度が上がる
- 初回は最小限、使いながら追加もOK

# 💡 よくある質問

**A:** いいえ！


**A:** 最短1分〜標準3分

- 最小限（必須3項目のみ）: 1分
- 標準（質問5も少し答える）: 3分
- 詳細（全部しっかり答える）: 5分
