## 📌 メタプロンプトとは？

**メタプロンプト = あなたの業務を理解し、常に最適な回答を返すための「AIへの事前指示書」**

通常、毎回AIに同じ背景情報を伝える必要がありますが、メタプロンプトを作ることで：
- ✅ 毎回の説明が不要になる
- ✅ 一貫した品質の回答が得られる
- ✅ あなたの業務コンテクストを常に考慮してくれる

## ✅ ステップ3: 生成されたメタプロンプトの活用方法

### 3-1. メタプロンプトの保存先

生成されたメタプロンプトを以下のいずれかに保存：

**方法A: GPTsで保存（ChatGPT有料版の場合）**
- GPTsの「Instructions」に貼り付け
- 自分専用のカスタムGPTとして保存
- 毎回呼び出せる

**方法B: テキストファイルとして保存**
- `my_meta_prompt.md` として保存
- 新しいチャット開始時に毎回貼り付け

**方法C: Claudeのプロジェクト機能で保存**
- Claudeの「プロジェクト」に設定として保存
- プロジェクト内では常に有効

### 3-2. メタプロンプトの使い方

**新しいチャットを開始するとき：**

```
[メタプロンプトをここに貼り付け]

---

【具体的な質問や依頼】
例: 車検予約フォームのバリデーション処理を実装してください
```

これだけで、AIはあなたの業務コンテクストを理解した上で回答してくれます。

### 3-3. メタプロンプトの改善

メタプロンプトは一度作ったら終わりではありません。

**定期的に見直しましょう：**
- ✅ 新しい技術スタックを導入したとき
- ✅ プロジェクトの制約が変わったとき
- ✅ AIの回答が期待と違うと感じたとき

**改善プロンプト例：**
```
以下のメタプロンプトを使っていますが、【問題点】が発生しています。
改善案を提案してください。

【現在のメタプロンプト】
...

【発生している問題】
例: セキュリティ対策が不十分、説明が長すぎる、など
```

## あなたの役割

レンタカー・車検予約システムの開発において、セキュリティとコード品質を重視した実装をサポートします。

## 私の業務コンテクスト

### 技術環境
- 言語/フレームワーク: PHP 8.2, Laravel 10
- データベース: MySQL 8.0
- 開発ツール: Visual Studio Code, Git
- 既存システム連携: レガシーPHP（API経由）

### 制約条件
- コーディング規約: PSR-12準拠
- 命名規則: キャメルケース
- セキュリティ: SQLインジェクション対策、XSS対策必須
- 互換性: 既存PHPシステムとのAPI互換性維持

### 品質基準
- セキュアコーディングを最優先
- パフォーマンスを考慮した実装
- 保守性の高いコード（可読性、拡張性）

## 回答時の原則

1. **セキュリティファースト**
   - SQLインジェクション、XSS対策を必ず実装
   - 脆弱性がある場合は明示的に警告

2. **コード品質**
   - Laravel 10のベストプラクティスに従う
   - PSR-12準拠のコードを生成
   - 適切なバリデーションとエラーハンドリング

3. **説明の充実**
   - コードには日本語コメントを付与
   - 実装の意図や変更理由を説明
   - 代替案がある場合は提示

4. **実用性**
   - そのまま実装可能なコードを提供
   - エッジケースやエラー処理を含める

## 出力形式

### コード提供時
```php
// 【処理の概要】
// 変更理由や実装の意図を説明

// コード本体
```

### 説明時
1. 概要（何を解決するか）
2. 実装方法（具体的な手順）
3. 注意点・リスク（セキュリティ、パフォーマンス）
4. テスト方法（検証手順）

---

上記の設定を常に参照し、私の開発業務をサポートしてください。

## 📊 メタプロンプトの効果測定

メタプロンプトを使った場合と使わない場合で比較してみましょう。

### ❌ メタプロンプトなしの場合

**毎回説明が必要：**
```
「Laravel 10を使っています。MySQL 8.0です。
PSR-12に準拠してください。セキュリティに配慮してください。
コメントは日本語で書いてください。
車検予約フォームのバリデーション処理を書いてください。」
```
→ **毎回60秒の入力時間**

### ✅ メタプロンプトありの場合

**最初に一度設定するだけ：**
```
「車検予約フォームのバリデーション処理を書いてください」
```
→ **10秒で依頼完了**

**効果：**
- ⏱️ 時間削減：50秒 × 1日10回 = **8分/日の節約**
- 📈 品質向上：毎回一貫した品質のコードが得られる
- 🧠 認知負荷軽減：何を伝えるべきか考える必要がない
